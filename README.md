# SA-MP Drift Server

Полнофункциональный дрифт сервер для San Andreas Multiplayer с системой рейтинга, уровней и наград.

## Возможности

✅ Система дрифта с подсчетом очков
✅ Рейтинг игроков
✅ Дрифт-зоны
✅ Награды за дрифт
✅ Система уровней
✅ Сохранение данных (без MySQL)
✅ Команды и админ-панель
✅ Эффекты и визуальные улучшения

## Структура проекта

```
├── gamemodes/
│   └── drift.pwn          # Основной файл сервера
├── filterscripts/
│   ├── drift_system.pwn   # Система дрифта
│   ├── drift_zones.pwn    # Зоны дрифта
│   ├── player_data.pwn    # Система сохранения данных
│   └── rewards.pwn        # Система наград
├── includes/
│   ├── drift.inc          # Дефайны и макросы
│   └── config.inc         # Конфигурация
├── scriptfiles/
│   └── players/           # Папка для сохранения профилей
└── server.cfg             # Конфигурация сервера
```

## Установка

1. Скопируйте файлы в папку SA-MP сервера
2. Откомпилируйте основной gamemode: `pawncc gamemodes/drift.pwn`
3. Скопируйте скомпилированный файл в папку gamemodes
4. Отредактируйте server.cfg
5. Запустите сервер

## Команды

### Игровые команды

- `/drift` - информация о дрифте
- `/stats` - показать статистику
- `/zones` - список дрифт-зон
- `/ranking` - таблица рейтинга
- `/level` - информация об уровне

### Админ команды

- `/adddrift [ID] [очки]` - добавить очки дрифта
- `/setzones` - создать дрифт-зону
- `/savedata` - сохранить данные всех игроков
- `/resetstats [ID]` - сбросить статистику игрока

## Системы

### Система дрифта

- Автоматический подсчет очков при дрифте
- Множители за длительные дрифты
- Комбо система
- Визуальные эффекты

### Рейтинг игроков

- Общий рейтинг по очкам
- Рейтинг по уровню
- Топ-10 игроков
- Ежедневный рейтинг

### Дрифт-зоны

- 10 предзагруженных зон
- Проверка входа/выхода из зоны
- Бонусные очки в зонах
- Индивидуальные рекорды зон

### Система уровней

- 50 уровней
- Опыт за дрифт
- Награды за новый уровень
- Привилегии высокого уровня

### Награды

- Деньги за дрифт
- Транспортные средства
- Скины для высоких уровней
- Медали и значки

## Сохранение данных

Данные игроков сохраняются в формате INI в папке `scriptfiles/players/`

Каждый игрок имеет файл: `scriptfiles/players/[ID]_[name].ini`

### Хранящиеся данные:

- ID и никнейм игрока
- Общие очки дрифта
- Уровень
- Опыт
- Деньги
- Рекорды по зонам
- Общая статистика
- Последнее посещение

## Конфигурация

Отредактируйте файл `includes/config.inc` для настройки:

```pawn
// Множители очков
#define BASE_DRIFT_POINTS 10
#define COMBO_MULTIPLIER 1.5
#define ZONE_BONUS 2.0

// Уровни
#define MAX_LEVEL 50
#define EXP_PER_LEVEL 1000

// Награды
#define MONEY_PER_DRIFT 50
#define VEHICLE_REWARD_LEVEL 20
```
